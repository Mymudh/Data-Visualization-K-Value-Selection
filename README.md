# Data Visualization & K-Value Selection

A beginner-friendly machine learning project covering **data visualization, K-value selection, feature scaling, and standardization** using Python and Scikit-learn.

## 📌 Project Overview

This project demonstrates how data visualization and preprocessing techniques can improve the understanding and performance of machine learning models.

The project focuses on exploring datasets visually, selecting an appropriate **K-value for KNN**, and understanding the importance of **feature scaling and standardization**.

## 🚀 Topics Covered

* Data Visualization
* Exploratory Data Analysis (EDA)
* K-Nearest Neighbors (KNN)
* K-Value Selection
* Feature Scaling
* Standardization
* Normalization
* Model Performance Comparison

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## 📊 Key Concepts

### Data Visualization

Used charts and plots to understand relationships, distributions, and patterns within the dataset.

### K-Value Selection

Tested different K-values in the KNN algorithm to identify a suitable value for better model performance.

### Feature Scaling

Demonstrated how features with different ranges can affect machine learning algorithms.

### Standardization

Applied standardization to transform features to a common scale, improving the performance of distance-based algorithms such as KNN.
